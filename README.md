# Exposição do TCC: Clean Code e Sem Clean Code em Python

Este repositório foi organizado como uma exposição do meu TCC, com o objetivo de mostrar, de forma prática e visual, a diferença entre códigos escritos com boas práticas de Clean Code e códigos escritos sem essas boas práticas.

## Objetivo

A ideia é apresentar exemplos em Python de algoritmos clássicos em duas versões:

- Clean Code: com nomes claros, funções bem organizadas, estrutura mais legível e manutenção facilitada.
- Sem Clean Code: com uma abordagem mais simples, menos organizada e mais difícil de compreender e evoluir.

## Estrutura do repositório

- python/CodeTCC/CleanCode/: exemplos em Python com enfoque em boas práticas de escrita e organização.
- python/CodeTCC/SemCleanCode/: exemplos em Python com a mesma lógica, mas sem a aplicação de princípios de Clean Code.

## Arquivos presentes

Os exemplos incluem algoritmos como:

- Bubble Sort
- Busca Binária
- Fatorial
- Maior Número
- Média de Três Números
- Número Primo

## Como usar

Para executar qualquer exemplo, acesse a pasta correspondente e rode o arquivo Python com o comando:

```bash
python nome_do_arquivo.py
```

## O que este repositório demonstra

Aqui é possível comparar diretamente como a organização, o nome das funções, a clareza do código e a divisão de responsabilidades influenciam na leitura, na manutenção e na compreensão do software.

Este projeto serve como material de apoio para a exposição do TCC, mostrando de forma objetiva como pequenas escolhas de escrita podem impactar bastante a qualidade do código.
